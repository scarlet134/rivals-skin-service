# RIVALS — сервис скинов для Discord

Небольшой read-only сервис: получает стандартный DDNet **0.6** скин из открытой базы,
собирает персонажа и отдаёт квадратный PNG 512×512 с прозрачным фоном.
Поддерживает обычные цвета и перекраску тела/ног в формате DDNet.
Красная гора добавляется **клиентом Discord через small_image: rivals_logo**, а не
рисуется внутрь скина. Код сервиса не меняет ваш игровой клиент.

## Запуск на Render

Загрузите все файлы и папку `test` в корень отдельного репозитория GitHub.
Создайте **Web Service**, подключите именно этот репозиторий:

- Language / Runtime: **Node**
- Branch: **main**
- Root Directory: оставить пустым
- Build Command: `npm ci --omit=dev`
- Start Command: `npm start`
- Instance Type: **Free**, если он доступен в вашем аккаунте
- Environment Variable: `NODE_VERSION` = `22`
- Health Check Path: `/health`

`render.yaml` содержит ту же конфигурацию для альтернативного развёртывания через Blueprint.
Если Render просит оплату или карту — остановитесь и проверьте настройки. Ничего
платного для этого пакета покупать не требуется, но наличие Free определяется Render.

После статуса Live откройте:

- `https://ВАШ-СЕРВИС.onrender.com/health`
- `https://ВАШ-СЕРВИС.onrender.com/skin.png?name=default`
- `https://ВАШ-СЕРВИС.onrender.com/skin.png?name=pinky&custom=1&body=65408&feet=9584384`

Адрес конкретного сервиса появится **после создания в Render**. Его нужно будет
передать модулю Discord в клиенте; один лишь запуск сервиса ещё не меняет активность.
Карту, ник, онлайн, время и кнопку продолжает отправлять сам игровой клиент.

## Ограничения

- Free-инстанс Render может засыпать при отсутствии запросов. Первый запрос после
  простоя будет медленным; Discord может закэшировать неудачную загрузку. Free —
  вариант для проверки, не гарантия непрерывной работы картинок у всех игроков.
- Только скины из доступных публичных баз. Файл, существующий лишь локально на ПК,
  не будет автоматически загружен. Для него сервис вернёт ошибку, а клиенту нужен
  возврат к логотипу RIVALS. Не подменяйте отсутствующий скин выдуманным.
- Не поддерживаются составные скины Teeworlds 0.7, игровые анимации, эмоции и оружие.
- Изменения картинок могут отображаться с задержкой из-за кэша Discord.

## API

`GET /skin.png?name=...&custom=0` — оригинальные цвета.

`GET /skin.png?name=...&custom=1&body=...&feet=...` — свои цвета.

`name` — UTF-8 название, кодируйте через encodeURIComponent / URL encoding;
`body` и `feet` — десятичные целые от 0 до 16777215.
`v=1` допустим как версия URL. URL файлов и других серверов сервис не принимает.
`GET /health` — готовность процесса. `HEAD` поддерживается. Ошибки — JSON.

## Безопасность и нагрузка

Нет токенов, базы пользователей, загрузок файлов или записи конфигурации.
Сервису передаются **только название скина и цвета**, без ника, карты и адреса игрового
сервера. Как любой хостинг, Render/прокси могут вести свои журналы HTTP-запросов.
Исходники скачиваются только с фиксированных HTTPS-хостов skins.ddnet.org и ddstats.tw;
редиректы запрещены, есть тайм-ауты, лимиты размера PNG, пикселей, кэша и параллельных
рендеров. Кэш изображений — до 24 MiB, исходников — до 12 MiB.

## Локальная проверка

Node.js 22 или новее:

```
npm ci
npm test
npm start
```

Откройте `http://localhost:10000/skin.png?name=default`.
Рендеры и HTTP проверены локально; реальный Render и отображение в Discord
нужно проверить после развёртывания и подключения клиентского модуля.
